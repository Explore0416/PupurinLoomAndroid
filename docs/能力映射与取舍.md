# 能力映射与取舍

本文档对照桌面版 `window.pupurin`（preload / main 进程）的完整 API 面，说明 Android 版的实现方式与不可避免的取舍。

## 1. 完整 API 能力映射

### 1.1 后端

| 桌面版 API | Android 实现 | 说明 |
| --- | --- | --- |
| `getBackendPort` | 返回 `null` | 无独立 Python 后端 |
| `getBackendStatus` | 返回 `{ running:false, port:null, pid:null }` | 解析已本地化，不再需要后端进程 |

## 2. 核心取舍

1. **不再有 Python 后端进程**：Ren'Py 脚本解析分别本地化为渲染层 TS（`parser.ts`）与 Kotlin（`ProjectStore`），整体更轻、完全离线可用。为此 `getBackendStatus` 恒返回「未运行」。

2. **项目存放公共共享目录而非私有沙盒**：项目内容存 `/storage/emulated/0/PupurinLoom/projects/`，用户在文件管理器 / 连接的电脑上可直接访问、备份与迁移。项目元数据（`projects.json`）、设置（`settings.json`）与插件状态等内部数据仍在应用私有目录。为写入公共共享目录，Android 11+（API 30）需要「所有文件访问」（`MANAGE_EXTERNAL_STORAGE`），Android 10 及以下需要「存储权限」，首次启动会引导授权；`pickDirectory` 因此不再需要用户选路径。

3. **设备端「打包」改为云端、设备端「运行」直接安装 APK**：真正的 RAPT 交叉编译（aapt2 / zipalign 为 x86_64 工具链）无法在手机本地离线完成，因此把「打包 APK / Web / PC」上移到打包服务器——App 上传项目 zip，服务器用 Ren'Py SDK 产出产物，App 轮询下载；默认走内置官方服务器（`maker.lightning-team.de5.net`），也支持在设置里填自建服务器地址。而「运行已导出的游戏」直接在设备端实现：SAF 选择已导出的 Ren'Py 游戏 APK → 复制到缓存 → 弹出系统安装器（API 26+ 自动引导「安装未知应用」授权）→ 安装完成后自动启动。该路径无需在 App 内嵌引擎，因为导出的 APK 自身携带引擎。若要进一步做到「内嵌引擎、以游戏目录直接启动」（不依赖 APK），需先运行 `tools/extract-renpy-runtime.sh <游戏apk>` 把引擎原生库（`lib/<abi>/*.so`）+ Python 运行时提取进 `app/src/main/jniLibs/` 与 `assets/renpy/`，再按实际引擎入口实现/校准 `PlayerActivity` 的本地引导（`hasRenpyEngine()` 会据此返回 true）。引擎二进制是真实产物、无法凭空生成，故这是一个标准化的提取/接入流程，而非代码可绕过的限制。

4. **插件禁止命令执行**：`pluginExec` 出于安全考虑不实现，返回说明。插件其余能力（面板、命令、受限文件读写、HTTP、商城）完整保留。

5. **无原生菜单栏**：桌面版顶部菜单在 Android 无对应物，相关 IPC 为 no-op，不影响核心编辑流程。

6. **布局适配的边界**：原版是桌面 IDE 布局。Android 版在渲染层注入了竖屏窄屏媒体查询（窄竖屏下禁横向溢出、弹性布局收窄、文字自动换行），手机竖屏已可用，平板横屏体验最佳。若需针对不同尺寸做更深度重排，需对前端做额外响应式改造（属于前端次优事项）。

## 3. 自适应与多窗口实现细节

- **横竖屏 / 多尺寸**：`screenOrientation="unspecified"`，`configChanges` 声明 `orientation|screenSize|screenLayout|smallestScreenSize|density|fontScale|locale|uiMode|keyboardHidden|keyboard|layoutDirection`，旋转/缩放不重建 Activity。
- **竖屏适配**：渲染层 `index.html` 注入窄竖屏媒体查询（`@media (max-width:860px) and (orientation:portrait)`），关闭横向溢出、允许弹性子项收缩、长文本自动换行，解决手机竖屏下的文字/布局溢出。
- **小米「无极缩放」自由窗口 / 分屏**：`resizeableActivity="true"`，未设置 `maxAspectRatio`，可任意比例缩放。
- **画中画（PiP）已移除**：为满足「放到后台不再悬浮窗口」的需求，已删除 `supportsPictureInPicture` 相关配置与 `onUserLeaveHint` / `onPictureInPictureModeChanged` 实现。按 Home / 切后台时应用正常退到后台，不再进入悬浮小窗。
